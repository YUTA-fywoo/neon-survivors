# 霓虹幸存者 · H5 割草原型

用 Claude Code 做的网页小游戏原型，手机和电脑都能玩。太空主题的割草类（类《吸血鬼幸存者》）玩法，加上模拟激励视频广告位和本机埋点面板，用来演示“做一个小游戏 → 看数据 → 按试玩反馈改”的完整流程。

- 在线试玩：https://yuta-fywoo.github.io/neon-survivors/ （手机、电脑都能直接打开；国内网络有时较慢）
- 迭代记录：[docs/iteration-log.md](docs/iteration-log.md)

## 玩法

- **操作**：手机在屏幕任意位置拖动移动，点右下角的技能圆钮放技能；电脑用 WASD 或方向键移动，空格或 E 放技能，F 领取广告空投，Esc 暂停，`` ` `` 或 F2 打开埋点面板。武器全部自动攻击。
- **一局**：6 波 × 34 秒，然后是 Boss 战，约 3 分半见到 Boss。每波分三段：0–22 秒敌人越来越多，22–30 秒是高峰（蜂群横穿、包围圈、精英、黑洞、陨石雨五种地图事件，事前 1.8 秒红色预警），30–34 秒停刷并自动回收经验。第 2、4、5 波会飞来一艘会逃跑的补给飞船，打爆掉主动技能（新星爆发、轨道轰炸、时停力场、相位护盾）。Boss 分三个阶段，血量打到 66% 和 33% 时崩掉一层装甲、升起护盾，要先打掉绕着它转的护盾发生器。
- **成长**：7 种武器（能量弹、环绕刃、脉冲波、闪电链、追踪导弹、集束炸弹、激光扫射）、7 种被动（含会连锁爆炸的殉爆），升级时三选一。每项强化带稀有度：普通 +1 级、稀有 +2 级、史诗 +3 级，用灰蓝紫三色标出；升级时约 4 成是稀有以上，宝箱里 85% 是稀有以上。武器满级再配上对应被动，下一个宝箱必出进化（传说，金色）。精英必掉宝箱，宝箱是仿 CS2 开箱的滚轴抽卡，4 成概率开出 3 项。
- **主角战机**：Lv 6、12、18 各进阶一次（侦察型 → 突击型 → 重装型 → 王牌型），机体越来越复杂；转向时侧倾；狂热时变形，展开金色光翼和副炮。
- **爽点**：击杀攒“狂热”能量，攒满后 7 秒射速和伤害大涨、画面跟着鼓点跳；短时间击杀 15 个以上放半秒慢动作；连着捡经验音一个比一个高；每种敌舰有自己的动作（悬停摇摆、拉长、起伏、开火前蓄力和后坐、摆尾、警示灯）。
- **局外**：结算金币可以买三项永久强化（生命、火力、机动）。

## AI 怎么参与的

| 谁 | 做了什么 |
|---|---|
| 本人 | 定玩法（割草幸存者）和最初的画风（几何霓虹）；试玩 v0.1 后提出 4 点反馈（升级和出怪节奏太快、设计语言 AI 感太强、要更吸引人、画面张力不够），从三个美术方向里选了“矢量街机”，从三种单局时长里选了“约 4 分钟到 Boss”；试玩 v0.2 后提出打击感不够、素材要更精细、可以做成太空主题，从三种素材做法里选了“代码画舰船 + AI 画背景”；试玩 v0.3 后要求加 WASD、大奖加抽卡动画、加创意内容、加快节奏，从四个创意候选里全选，并自己提出升级稀有度和补给飞船掉主动技能；做 v0.4 途中又要求加解压的范围武器、想办法刺激多巴胺、给所有角色加动作、抽卡改成 CS2 开箱；试玩 v0.4 后要求提高稀有度爆率、武器特效别那么廉价，并提出主角战机转向侧倾、爆发时变形、随等级变高级；试玩 v0.5 后要求广告奖励更想让人点、但看广告变强后敌人要跟着变强（“较有提升而不是直接无敌”），技能按钮要有存在感，全部界面加动效、升级设计感；试玩 v0.6 后指出 Boss 血太少（“几秒钟秒了”），要求敌人和场地效果更精致，并提出黑洞要有视觉扭曲、会吸主角；试玩 v0.7 后指出黑洞还看不到扭曲、吸力不够，陨石坑太丑，Boss 各阶段外形差别太小；试玩 v0.8 后指出音效廉价，要求提升质感 |
| Claude Code | 给出每个决定的候选方案；写全部代码，包括用代码画的全部舰船；查同类游戏的数值（《吸血鬼幸存者》经验公式和出怪表、《Brotato》波次时长、《求生之路》AI 导演）和游戏吸引力研究，把它们落成具体设计；写自动试玩 bot，用它把难度校准到目标区间；自测并修 bug |
| 本机生图模型 | 星云背景图：Qwen-Image 2.1 在本人电脑上（RTX 5070 + ComfyUI）生成，提示词和挑选由 Claude Code 完成 |

每处改动对应的依据、bot 前后对比都在[迭代记录](docs/iteration-log.md)里。

## 广告位设计（模拟，未接真实 SDK）

没有接任何广告 SDK。广告页是一段 5 秒的占位动画，所有广告按钮和广告页都标了“广告 · 演示”。上线时换成广告聚合 SDK 的激励视频接口即可，打点和发奖逻辑不用动。

| 广告位 | 什么时候出现 | 奖励 | 每局上限 |
|---|---|---|---|
| 开局增益 | 主菜单 | 开局先来一次史诗强化三选一 | 1 次 |
| 三项全拿 | 升级三选一时（金色主按钮） | 三张卡全部拿走 | 2 次 |
| 刷新强化 | 升级三选一时（次要按钮） | 换一组选项 | 2 次 |
| 宝箱再抽 | 开宝箱后 | 再抽 1 项，保底史诗（能进化时出进化） | 2 次，每个宝箱 1 次 |
| 波间空投 | 第 1、3、5 波打完的喘息段，左下角限时 9 秒 | 随机一种，写在卡上：火力全开（40 秒伤害 +50%、射速 +30%）、史诗补给箱、双倍经验（下一波） | 3 次 |
| 复活 | 死亡后 8 秒倒计时 | 满血、3 秒无敌、立刻进入狂热，震开周围敌人；复活页写出离 Boss 还差几波 | 1 次 |
| 金币倍率 | 结算页 | 指针在 ×2 / ×3 / ×5 倍率条上来回摆，按下时停在哪格拿几倍（平均约 2.5 倍） | 1 次 |

- 全部是玩家主动点的激励视频，没有插屏。位置都选在玩家最想要“再多一点”的时刻：开局前、三张卡都想要时、开宝箱的兴奋点、波次之间的喘息段、快输时、结算时。按钮和广告页都直接写出看完拿到什么。
- **威胁度**：每靠广告拿一次永久强化（开局增益、三项全拿、宝箱再抽、史诗补给箱、双倍经验、复活），之后刷出的敌人就更硬、更疼、更多（多出来的不给经验），Boss 也更硬。HUD 上挂“敌军 Lv N”。用 bot 校准过（v0.7 复核）：全看广告的 bot 通关率从 70% 到 100%，平均高约 5 级、击杀多约 65%，Boss 战比不看广告短约六分之一，最低血量差不多。看广告明显变强，但不是直接无敌。系数在 `js/config.js` 的 `threat` 里。
- 中途点“跳过”会先暂停视频并确认“放弃奖励？”，避免误触白看。
- 埋点面板里可以把填充率调成 100% / 70% / 0%、时长调成 5 / 15 / 30 秒，用来测无填充和长视频时的体验。

## 埋点设计

所有事件存在本机浏览器（localStorage，最多 6000 条），不上传。每条带事件名、时间、会话 id、版本号和本局 id，可以在面板里导出 JSON。

| 类别 | 事件 |
|---|---|
| 会话与对局 | `session_start` `game_start` `game_end`（结果、时长、波次、等级、击杀、最高连杀） `game_win` |
| 关卡进度 | `wave_reach` `wave_clear` `boss_spawn` `boss_phase`（进入第几阶段） `boss_shield`（这次破盾用了多久） |
| 成长 | `level_up` `upgrade_pick`（带稀有度和来源：升级、开局增益、三项全拿） `upgrade_reroll` `chest_open`（带最高稀有度） `evolve` `ship_tier`（战机进阶） `shop_buy` |
| 地图事件与技能 | `map_event` `supply_spawn` `supply_kill` `supply_escape` `skill_pickup` `skill_use` |
| 爽点 | `fever`（第几次狂热） `massacre`（触发清场慢动作） |
| 死亡 | `player_death`（时间、波次、等级、最后伤到自己的敌人） `revive` |
| 威胁度 | `threat`（哪种广告奖励、加完后的威胁度） |
| 广告漏斗 | `ad_offer` → `ad_click` → `ad_no_fill` / `ad_play` → `ad_complete` → `ad_reward`，中途放弃记 `ad_close_early`（含已看秒数），都带广告位名 |

埋点面板（主页和暂停页的“埋点面板”按钮，或结算页的“看这局的埋点”）可以按版本筛选，回答这几个问题：

- **玩家卡在哪**：关卡进度漏斗按局去重，从开局、第 2–6 波、Boss 战到通关，标出流失最多的一步。
- **玩家死于什么**：死亡点按波次和死因统计。
- **广告位有没有人要**：每个广告位的曝光 → 点击 → 播放 → 看完 → 发奖转化率。
- **改数值有没有用**：Bot 回归按版本对比平均存活、等级、到达 Boss、通关率和最低血量，看广告和不看广告分开统计。

用过调试工具（无敌、跳到 Boss、直接升级、bot 试玩）的局会打标记，不计入漏斗、死亡点和广告统计。

## 试玩后改了什么

本人试玩 v0.1 后，v0.2 按 4 点反馈改了节奏、吸引力、画面张力和设计语言，摘要如下（详见[迭代记录](docs/iteration-log.md)）：

- **节奏**：每波 25 秒 → 40 秒，并加上蓄力、高峰、喘息三段；升级经验改成《吸血鬼幸存者》前 20 级的公式（5、15、25……）；出怪改成每波规定最少在场数。只放慢会太简单，又用 bot 校准了三轮，最后收紧了后期敌人的伤害和 Boss。
- **吸引力**：按 Kao 等（CHI 2024）“好奇心是乐趣和游玩时长最强的预测因素”“反馈要跟成绩挂钩”，加了武器进化、宝箱揭晓、暴击、连杀里程碑和高峰段地图事件。
- **画面张力**：网格受爆炸冲击会弯曲回弹、磷光拖影、顿帧和整屏闪光、镜头随波次拉远、高峰段网格变红、屏幕外威胁给边缘箭头。
- **设计语言**：去掉紫青渐变、毛玻璃、发光按钮和 emoji，改成纯黑底、只描线的矢量图形、直角括号框、等宽数字和扫描线，配色只留青、琥珀、红三色。

| bot 各 10 局 | v0.1.0 | v0.2.0 |
|---|---|---|
| 平均存活 | 2:47 | 5:02 |
| 平均等级 | 8.0 | 12.9 |
| 到达 Boss | 60% | 80% |
| 通关 | 0% | 60% |

本人试玩 v0.2 后觉得打击感不够、素材不够精细。v0.3 没有改数值，只改表现：

- **打击感**：命中有白光、顺着攻击方向的火花和敌人弹一下；击杀改成四档爆炸（闪光、光团、冲击圈、火花、旋转残骸），装甲舰和精英加顿帧；子弹改成等离子弹，开火有枪口闪光和后坐；音效加了白噪声的“啪”和“轰”。震屏和顿帧仍只给大敌人和连杀里程碑。
- **太空主题**：背景是本机生图模型画的星云，加两层视差星星；舰船全部用代码画，深色金属机身、倒角高光、霓虹描边、舱段线、发光灯和尾焰，每种敌人有普通、闪白、精英三套。

bot 回归 10 局：通关 80%、平均存活 5:27，和 v0.2 的差别在随机波动范围内。

本人试玩 v0.3 后提了 WASD、抽卡动画、创意内容、节奏 4 点，做到一半又补了解压武器、多巴胺、角色动作、CS2 开箱 4 点。v0.4：

- **WASD**：其实已经能用，只是提示只写了拖动。改成按设备显示提示，电脑开局亮按键提示，兼容中文输入法。
- **稀有度和抽卡**：升级分普通、稀有、史诗、传说四档，档次就是一次涨几级；宝箱改成 CS2 式滚轴，停点旁边常放一格传说制造“差一点”（只影响显示，不改概率）。
- **创意内容**：黑洞、陨石雨、补给飞船和它掉的 4 种主动技能、追踪导弹。
- **解压和多巴胺**：集束炸弹、激光扫射、殉爆连锁；狂热、清场慢动作、连捡音阶、经验喷泉、升级震波伤人。
- **动作**：每种敌舰一套动作，加上出生弹出、转弯侧倾、挨打歪斜、引擎尾焰。
- **节奏**：每波 40 秒 → 34 秒，4:00 → 3:24 见 Boss，前 3 波开场敌人更多。

新内容让玩家强了很多（第一轮 bot 9 局全通关），用 bot 校准了五轮：后几波敌人更多、成长更快，Boss 弹幕更密，定稿 bot 通关 70%、平均存活 4:50，过程在[迭代记录](docs/iteration-log.md#bot-校准)。

本人试玩 v0.4 后觉得稀有度爆率太低、武器特效廉价，并提出主角战机要更有动态。v0.5：

- **爆率**：升级时至少一张稀有以上的概率从约 32% 提到约 78%；宝箱稀有以上从 50% 提到 85%，开出 3 项从 25% 提到 40%。
- **武器特效**：加了十字星芒、冲击环、等离子弹、火球 4 张特效贴图，命中、开火、9 种效果全部重做（闪电分叉、导弹光带尾迹、环绕刃弧形光带、冲击波速度线、炸弹火球等）。
- **主角战机**：转向时平滑转头并侧倾（假 3D 明暗）、急转弯翼尖拉气流；Lv 6、12、18 进阶换机体，有聚能、炸壳、换装的进阶动画；狂热时变身，光翼转出、副炮滑出、机身转金，结束时收回。

爆率提高后 bot 第一轮又是 9/10 通关。加强普通敌人基本没用，起作用的是 Boss 每次召唤的杂兵数，校准了六轮，定稿是敌人成长略升（生命 +85% → +90%/分，伤害 +40% → +45%/分），Boss 每次召唤 12 → 14 只、弹幕更密更疼。bot 通关仍是 70%，平均存活 5:26。没通关的 3 局都是 Boss 战拖到 bot 的 7 分钟上限，没有一局被打死，过程在[迭代记录](docs/iteration-log.md#bot-回归)。

本人试玩 v0.5 后要求广告奖励更想让人点、但看广告变强后敌人要跟着变强，技能按钮要有存在感，全部界面加动效、升级设计感。v0.6：

- **广告奖励**：新增开局增益、三项全拿、波间空投三个广告位；宝箱再抽改成保底史诗，复活改成满血加狂热，金币翻倍改成要按准时机的倍率条。按钮统一成金色并写明奖励。
- **威胁度**：靠广告拿到永久强化后敌人跟着变强，HUD 显示“敌军 Lv N”。bot 校准了四轮，前两轮只加敌人生命和伤害，全看广告的 bot 还是 10/10 通关、几乎不掉血；改成同时增加敌人数量，并让多刷的敌人不给经验，才达到“明显变强但仗还要打”。
- **技能按钮**：右下角常驻大圆钮，空着时是技能槽；拿到时弹出，平时呼吸发光、外扩波纹，危险时抖动提示“现在释放！”，放掉时炸一圈光。
- **界面**：切角按钮、玻璃面板、四角括号从角上长出、卡片翻转弹入、血条残影、数字滚动、倍率条、横幅光线收拢等，所有界面都加了入场和反馈动效；系统开了“减少动态效果”时关掉循环动画。

本人试玩 v0.6 后指出 Boss 几秒钟就打死了，要求敌人和场地效果更精致，并提出黑洞要有视觉扭曲、会吸主角。v0.7：

- **Boss**：实测 27 级的主角贴身打每秒 380–730 伤害，4500 血 6–12 秒就没了；之前 bot 校准没发现，是因为 bot 在 Boss 战里一直去捡经验，离 Boss 很远。血量改成 20000，并分成三个阶段：打到 66% 和 33% 时崩掉一层装甲、升起护盾，放出 4 / 5 座绕着转的护盾发生器，全打掉才破盾，破盾后硬直 2 秒、受伤 +50%。一下打穿也停在门槛上，阶段跳不过去。后两个阶段加螺旋弹幕、冲撞更频繁。bot 改成贴身打 Boss、开盾时去拆发生器、躲黑洞和陨石，校准了六轮，定稿通关率仍是 7/10，Boss 战约两分钟，拆一次盾约 10 秒；估计真人贴身打约 1 分钟。全看广告时 Boss 被高输出压得太快，Boss 的威胁度系数从 1.2 提到 1.8，看广告的 Boss 战仍只比不看的短约六分之一。
- **敌舰**：加了凹面板、格栅、铆钉、玻璃罩、喷口、能量线、警示条纹一套零件，6 种敌舰和补给飞船全部重画；装甲舰炮塔单独转动；Boss 三个阶段三套外形；新敌人护盾发生器；精英从传送门里钻出来，身上一圈转动的危险环。
- **黑洞**：引力透镜把周围画面一圈圈放大、扭转，背景和敌人都被拉弯（敌弹和主角不扭曲，不影响躲避）；中间是吸积盘、纯黑视界和光子环；吸主角的力量加大到接近主角移速，被拽住时机身拉出光丝。

本人试玩 v0.8 后指出音效廉价。v0.8.1 只改音效：

- **原因**：旧音效是方波、锯齿波直接出声，不过滤波，没有空间感，每次播放一模一样，连续开火、击中时又尖又像机关枪。
- **做法**：仍然全部用代码合成、不加载音频文件，但改成页面加载时离线渲染成采样（38 种音效、93 份，本机约 0.75 秒渲染完）。每个音效分层做：起音的“啪”、低频冲击、主体、尾巴；滤波器带包络，低频过软削波，手机外放也听得出“轰”；铃声和金属声用调频；和弦用去谐的锯齿波；同一个音效渲染几份略有差别的版本，播放时再随机微调音高和音量。击中、击杀、爆炸按画面位置放到左右声道。总线上加压缩、限幅和卷积混响。
- **校准**：新旧音效在离线环境里逐个渲染对比。按模拟手机外放的加权响度，单个音效和旧版基本持平（±3 dB）；开火、击中这类最频繁的声音亮度（频谱重心）降了一半以上，不再刺耳；所有音效和 3 秒密集战斗压力测试都没有削波。
- 只改了音效，没动数值，没有重跑 bot。
